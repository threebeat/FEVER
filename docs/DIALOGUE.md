# FEVER recording script

The game reads these tables directly. Each cue has a stable recording ID. The seconds specify its minimum caption duration. Higher priorities interrupt ambient conversation. Record each line dry as mono 48 kHz, 16-bit PCM WAV and name it for its cue, for example `assets/voice/LA_004.wav`. The mixer places a world take at the speaker and applies radio filtering to radio takes. Missing takes play as captions with the environmental sound left in place.
